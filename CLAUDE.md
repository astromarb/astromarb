## Project Overview

This is the GitHub profile repository for a Masters student researching thermodynamic modeling of Cretaceous, highly differentiated silicic magma/mush/melt systems. The repository intersection spans physics, geoscience, and computer science.

## Repository Structure

Currently, this repository contains only the profile README. Future code contributions may include:
- Thermodynamic modeling simulations
- Data processing and analysis scripts
- Geochemical or mineralogical computation
- Scientific visualization tools

## Development Setup

When adding code to this repository:
- Choose appropriate tools for scientific computing (e.g., Python with NumPy/SciPy, MATLAB, or language-specific scientific libraries)
- Include documentation explaining the physical models and assumptions
- Consider reproducibility: document data sources, parameter values, and methodology
- Add relevant metadata about what physical system or time period the code models

## Guidelines for Contributors

- Prioritize clarity and documentation for scientific code
- Include unit tests where applicable to verify numerical accuracy
- Consider computational performance for simulations
- Link code to published research or methodological papers where relevant
